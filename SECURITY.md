# Security policy

This repository is a starter, not a hosted service. Only the `main` branch is maintained.

## Reporting a vulnerability

Please report vulnerabilities privately, through GitHub's private vulnerability reporting: **Security** tab, then **Report a vulnerability**. Do not open a public issue for a security problem.

A useful report says which part of the code is affected, how to reproduce the problem, and what an attacker could do with it.

The dependency policy (CVE audits in CI, Dependabot updates, how an exception is documented) is in [`security/README.md`](security/README.md).
